ℹ️ About third-party plugins and recovery

Third-party plugins can cause InkyPi to fail to start, for example if they rely on dependencies that are not installed. The install process installs dependencies from the plugin’s requirements.txt, but if there are more, fixing the issue by installing missing packages yourself can be tricky.

In most cases you can recover by connecting via SSH, removing the plugin folder, and restarting the service. Replace PLUGIN_FOLDER with the actual plugin directory name: 

ls ~/InkyPi/src/plugins


sudo rm -rf ~/InkyPi/src/plugins/PLUGIN_FOLDER


sudo systemctl restart inkypi.service

Recommendation: keep those commands somewhere safe. If InkyPi does not start, this page will not be available.
